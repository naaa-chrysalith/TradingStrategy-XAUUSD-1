## 🛠️ Setup

### Prerequisites
- MetaTrader 5 installed
- Basic MQL5 knowledge
- Git installed

### Quick Start

1. Clone this repository:
```bash
git clone https://github.com/naaa-chrysalith/TradingStrategy-Personal.git
cd TradingStrategy-Personal
```

2. Copy strategy files (.mq5) to MetaTrader 5 Experts folder:
   - Windows: `C:\Users\YourUsername\AppData\Roaming\MetaTrader 5\MQL5\Experts\`
   - Mac: `~/Library/Application Support/MetaTrader 5/MQL5/Experts/`

3. Compile and test in MetaTrader 5

For detailed setup, see [SETUP.md](./Docs/SETUP.md)
