# Technical Indicators Reference

## Volume & Volatility Indicators

### Bollinger Bands
- **Formula**: SMA(20) ± (2 × StdDev)
- **Usage**: Identify overbought/oversold
- **Trading Signal**: Price touches band = reversal likely

### ATR (Average True Range)
- **Formula**: Average of True Range (14 periods)
- **Usage**: Measure volatility
- **Trading Signal**: ATR > [threshold] = High volatility = Good entry

### Volume Profile
- **Usage**: Identify support/resistance clusters
- **Trading Signal**: Price near high-volume node = reversal zone

### VWAP (Volume Weighted Average Price)
- **Usage**: Fair value indicator
- **Trading Signal**: Price above VWAP = Bullish, Below = Bearish

## Price Action Indicators
- Support/Resistance levels
- Candlestick patterns
- Trend lines
